**FinAI** là tiện ích mở rộng trên trình duyệt Chrome được thiết kế riêng cho các nhà đầu tư mới (F0). Tiện ích giúp loại bỏ rào cản thuật ngữ phức tạp khi đọc tin tức tài chính (CafeF, Vietstock, VnExpress...) bằng cách phân tích ngữ cảnh và giải thích dễ hiểu ngay khi bôi đen văn bản.

---

### ✨ Tính năng nổi bật
- **Tra cứu tức thì**: Chỉ cần bôi đen thuật ngữ chuyên ngành trên mọi website.
- **Phân tích theo ngữ cảnh**: Giải thích ý nghĩa của từ đặt trong chính câu văn đang đọc kèm ví dụ số liệu thực tế.
- **Hỗ trợ song ngữ**: Chuẩn hóa cả thuật ngữ Việt Nam (T+2, Room ngoại, Biên độ...) và Quốc tế (P/E, RSI, Margin Call...).
- **Thiết kế Organic & Thân thiện**: Phong cách Cozy Green lấy cảm hứng từ thiên nhiên, bảo vệ mắt.
- **Bảo mật & Miễn phí**: Vận hành qua Cloudflare Worker Proxy — bảo mật API Key tuyệt đối, người dùng cài là dùng ngay 100%.
